## describe_corpus

```text
Describe what is loaded: datasets, time spans, components and their teams, levels, template and episode counts.
Use it to: orient before any other call; find exact component/level names, the time span to query, which team owns what.
Do NOT use it to: count or rank problems in a period — use count_by or recurring_problems instead.
Inputs: dataset bgl|openstack|both (default both); role.
Returns: datasets[] with rows, from/to, components (name, team, rows), levels, templates, episodes, episode_gap, labelled_rows; ownership_unmapped_rows; notes; plus receipt_id, summary, total_matches, truncated, sql and caveats.
```

| `role` | `engineer` \| `team_lead` \| `manager` \| `unknown` | `"unknown"` | Who the answer is for; pass it on every call. |

## search_logs

```text
Full-text search of log lines in SereneDB (BM25-ranked), returning a small sample of the most relevant lines with highlights.
Use it to: find concrete examples of a message, error or node; get line ids to anchor get_timeline.
Do NOT use it to: count how often something happens or compare frequencies — the lines are a sample; use count_by or recurring_problems instead.
Inputs: query (required); dataset bgl|openstack (required); start/end ISO (date-only end includes the day); component; level; source (BGL node / OpenStack service); match terms (all words, default)|phrase (exact order)|fuzzy (1 edit per word); limit default 20, max 50; role.
Returns: lines[] (id, ts, source, component, level, message, template_id, episode_id, highlights), query, match; total_matches = all matching lines; plus receipt_id, summary, total_matches, truncated, sql and caveats.
```

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `query` | `string` | required | Words or phrase to find in the log message, e.g. 'TLB error'. |
| `dataset` | `bgl` \| `openstack` | required | Which dataset to search. |
| `start` | `string` \| `null` | `null` | Inclusive start, ISO (YYYY-MM-DD[THH:MM[:SS]]). Default: start of the dataset. |
| `end` | `string` \| `null` | `null` | End, ISO. A date-only end includes that whole day. Default: end of the dataset. |
| `component` | `string` \| `null` | `null` | BGL component (e.g. KERNEL) or OpenStack service. |
| `level` | `string` \| `null` | `null` | Exact level, e.g. FATAL, ERROR, WARNING. |
| `source` | `string` \| `null` | `null` | BGL node (e.g. R02-M1-N0-C:J12-U11) or OpenStack service. |
| `match` | `terms` \| `phrase` \| `fuzzy` | `"terms"` | terms = all words appear; phrase = exact word order; fuzzy = each word within 1 edit. |
| `limit` | `integer` | `20` | Lines to return, default 20, max 50. |
| `role` | `engineer` \| `team_lead` \| `manager` \| `unknown` | `"unknown"` | Who the answer is for; pass it on every call. |

## get_timeline

```text
Show what happened around one line or moment on the same midplane/node (BGL) or service/instance (OpenStack), repeats collapsed by template.
Use it to: see precursors and consequences of an error; build the engineer's incident story.
Do NOT use it to: test whether a precursor is a general pattern — one timeline is one case; use test_hypothesis instead.
Inputs: dataset; exactly one of anchor_id (line id from search_logs) or at (ISO time, then scope_value is required); scope node|midplane|service|instance|dataset (default midplane / service); before_s default 600, after_s default 300 (max 21600 each); collapse default true; role.
Returns: anchor line, window, before[] and after[] groups (template_id, template_text, level, count, first_ts, last_ts, sample line; max 40 per side); total_matches = lines in window; plus receipt_id, summary, total_matches, truncated, sql and caveats.
```

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `dataset` | `bgl` \| `openstack` | required | Which dataset. |
| `anchor_id` | `integer` \| `null` | `null` | Line id to centre on (from search_logs). Give exactly one of anchor_id or at. |
| `at` | `string` \| `null` | `null` | ISO time to centre on instead of a line; needs scope_value unless scope='dataset'. |
| `scope` | `node` \| `midplane` \| `service` \| `instance` \| `dataset` \| `null` | `null` | Which lines count as context: BGL node/midplane (default midplane), OpenStack service/instance (default service), or the whole dataset. |
| `scope_value` | `string` \| `null` | `null` | Scope value when `at` is used, e.g. 'R23-M0' or 'nova-compute'. |
| `before_s` | `integer` | `600` | Seconds before the anchor, default 600, max 21600. |
| `after_s` | `integer` | `300` | Seconds after the anchor, default 300, max 21600. |
| `collapse` | `boolean` | `true` | Group repeated lines by template (default true). |
| `role` | `engineer` \| `team_lead` \| `manager` \| `unknown` | `"unknown"` | Who the answer is for; pass it on every call. |

## rank_risks

```text
Rank problems for a manager by a transparent score from measured frequency (F), spread (S), trend (T), severity (V) and labelled share (L), with a stability check.
Use it to: decide what to fix first and who owns it.
Do NOT use it to: find an engineer's root cause — use get_timeline and test_hypothesis; the score says nothing about business impact.
Inputs: dataset bgl|openstack|both (default both); start/end (default last 30 days of each dataset); top_n default 5, max 10; min_episodes default 2; weights optional {F,S,T,V,L} (default .30/.25/.20/.15/.10, renormalised); role.
Returns: weights, items[] (rank, template_id, title, dataset, team, score 0–100, inputs F..L, raw measured values, stability_top3 = share of 10 weight variants keeping it in the top 3); plus receipt_id, summary, total_matches, truncated, sql and caveats.
```

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `dataset` | `bgl` \| `openstack` \| `both` | `"both"` | Which dataset(s). |
| `start` | `string` \| `null` | `null` | Inclusive ISO start. Default: 30 days before end. |
| `end` | `string` \| `null` | `null` | ISO end. Default: end of each dataset. |
| `top_n` | `integer` | `5` | Risks to return, default 5, max 10. |

## test_hypothesis

Inputs: dataset bgl|openstack; cause_template_id; effect_template_id (from search_logs/get_timeline/recurring_problems); window_s default 600, max 3600; scope midplane|node (BGL, default midplane) or service|instance (OpenStack, default service); start/end; role.
Returns: effect_episodes, supported_episodes, forward/reverse (support, baseline, lift), baseline_windows/hits, 3 examples, 3 counter_examples, verdict strong|moderate|weak|none|insufficient_data; plus receipt_id, summary, total_matches, truncated, sql and caveats.

## check_answer

```text
Check a draft answer before sending it: every number, percentage and date must match a receipt the sentence cites.
Use it to: catch unbacked, mismatched or invented claims, causal words in Observed and impact words outside Unknowns. Call it LAST, fix every problem it lists, then answer.
Do NOT use it to: look up data — it runs no queries; use get_receipt to read a receipt.
Inputs: draft (markdown with [R-0001]-style citations, ideally Scope / Observed / Hypotheses / Unknowns / Next step); role.
Returns: ok, counts (backed, unbacked, mismatched, flagged), claims[] (text, kind, status, receipt_ids, note); also updates the console status bar; plus receipt_id, summary, total_matches, truncated, sql and caveats.
```

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `draft` | `string` | required | Your full draft answer (markdown) with [R-0001]-style citations. |
| `role` | `engineer` \| `team_lead` \| `manager` \| `unknown` | `"unknown"` | Who the answer is for; pass it on every call. |

## show_evidence
