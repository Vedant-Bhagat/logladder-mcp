It says what it can’t know

A plain-Python checker compares every number in Claude’s draft with the receipts it cites, and flags words like downtime, cost or customers that no query measured.

> How much downtime and money did the rts panics cost us?

I can’t tell you the downtime or money. The BGL logs record how often rts panics happen, not how long anything was down or what it cost.

Run it yourself

Everything runs on your machine: SereneDB in Docker, the MCP server started by your own Claude Code, and an optional console in your browser.

  • Needs Python 3.11+, Node 20+, Docker Desktop and Claude Code.
  • The full load takes about 5 minutes.
  • Then pick a role and ask, or run /mcp__loglad__investigate.
# from the repo root
python tasks.py setup
python tasks.py db
python tasks.py fetch
python tasks.py data
python tasks.py console
